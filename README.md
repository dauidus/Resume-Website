# Resume-Website
 use this to build your own online resume!

To use this, simply clone it or fork it, then add it to your Github Desktop App, like we talked about in class.

If you're not a CS major, the easiest way to edit these files is to download the free Visual Studio Code app.  Available on all platforms.  This is what the rest of us use, pretty much.  

Once you have that app, simply edit the index.html file (you don't really need to edit anything else), and focus on the white text only - it's white for me, at least.  It's ok... small changes, with many small commits...  it's pretty impossible to lose any changes, if you do it right.  Remember?

Can't wait to see what you all create from this.  Go crazy.  You own it now.  It is yours.
